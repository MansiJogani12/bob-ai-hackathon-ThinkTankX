# Screenshots

Place the ThinkTankX application screenshots in this folder.

## Naming Convention

Screenshots are named in sequence so they appear in a logical review order:

- `02-main-feature.jpg` - Main YieldSentinel AI dashboard and primary wafer-yield workflow
- `03-compare-analysis.jpeg` - Comparison and analysis view for reviewing yield intelligence
- `04-batch-predication.jpeg` - Batch prediction and multi-wafer risk analysis

The current repository contains three screenshots. The numbering begins at `02` because the original landing-page image is not included in the current checkout.

## Requirements

- Minimum: 3 screenshots
- Format: JPG or PNG
- Show the YieldSentinel AI dashboard running with real or realistic wafer and batch analysis data
- Include meaningful application views rather than empty states or template placeholders
- Captions are documented above for each available screenshot

## Tips

- Use a consistent browser window size across all screenshots.
- Highlight important risk scores, prediction results, SHAP contributors, or dashboard metrics when useful.
- Include the batch-risk and comparison workflows because they show the main value of the project.
- IBM technology integration is not shown because the current implementation does not directly use watsonx.ai or another IBM platform service.
- Keep screenshots focused on the implemented YieldSentinel AI workflow: wafer prediction, batch risk, explainability, and engineering investigation.
